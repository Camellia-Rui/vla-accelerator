# Permanently retired and quarantined methods

This file is a binding project boundary for every Codex using this release.

## AutoPrune — permanently retired

AutoPrune is permanently archived by explicit user decision. It is not a candidate for integration, evaluation, tuning, optimization, packaging, or deployment.

- Do not search older workspace folders or ZIPs for its source.
- Do not recreate its algorithm, adapter, attention-prior bridge, configuration flags, tests, or examples from history.
- Do not relabel the same implementation as generic current-frame prefix pruning.
- If a request appears to require AutoPrune, stop that route and ask the user to choose a different method. Only a future explicit user instruction that revokes this retirement can change the boundary.

The release contains no AutoPrune executable source. Mentions of its name exist only in retirement instructions and integrity checks.

## VLA-Cache — quarantined after failed closed-loop acceptance

The tested implementation is rejected for deployment. Archived raw results may be read to explain the decision, but no overlay or installer is bundled. Reopening requires an explicit user decision and a materially redesigned algorithm; parameter micro-scans do not qualify.

## Unrelated project

GRIDs/OpenPI is excluded and its results must not be mixed into this project's evidence.
