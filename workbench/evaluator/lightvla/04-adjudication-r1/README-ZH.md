# 更新版 LightVLA：任务 0/3 定向复核 r1

前一阶段总体成功数持平，但任务 0 多成功一次、任务 3 少成功一次。本包只接受该单门槛失败模式，然后使用未见过的初态 5--19，对任务 0 和 3 各追加十五个 baseline/packaged 配对 episode，共 60 个新 episode。

每个 episode 创建全新环境；模式顺序交替；推理使用官方双图、proprio、L1 action head 和 8-action chunk。最终合并上一阶段证据，共形成 50 个配对初态。总体与逐任务成功率下降均不得超过 5%，同时继续要求无错误、权重不变、实际裁剪和至少 1.03 倍查询加速。
