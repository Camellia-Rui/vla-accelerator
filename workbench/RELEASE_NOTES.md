# Release 2026-11-02-r6

- 新增 evaluator/specprune 和 evaluator/vla-pruner 的显式配置与无模型预检。
- 新增公共配对 bootstrap、严格身份配对、原子记录、错误重试、计算前输入 hook 和抽样/卸载审计。
- 仅进行离线/CPU 基础设施测试；没有创建空阶段或宣称完整真实评估器已完成。
- 等待服务器源码/API、权重、任务资产及环境确认后，才进行实际方法适配。

## 继承 r5 的修复

- 独立维护版，保留 r3/r4 原件和算法资产。
- 初始化改为校验与只读盘点，不自动执行历史任务或 builder 任务。
- 补齐项目状态、证据索引、并行协作和不导入模型的环境探测工具。
- 统一版本身份，修复 r3/r4 残留路径；增强交接验证。
- 强化结果门控，拒绝 NaN/Inf、错误类型、缺失证据文件和未测试 control。
- SpecPrune/VLA-Pruner 真实五阶段评估器仍未完成，不能冒称已验证。
- 没有启动 GPU/闭环/训练/真机实验，没有修改模型权重。
