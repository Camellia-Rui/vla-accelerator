# 0.2.0-rc1 发布候选状态

## 已完成

- 统一根入口、中文使用指南和 Codex Skill；历史 evaluator 入口归档，评估组件统一置于 workbench。
- 标准库工作目录检查，生成 HTML/Markdown/JSON，有限深度与体积扫描，不导入用户源码。
- LightVLA 真实 CPU tiny LLaMA 演示：原生、剪枝、卸载恢复；已有用户工厂入口接入统一运行脚本。
- 四方法状态目录、证据边界和中期演示流程。
- 白名单源码发布构建与逐文件校验，拒绝丢失、变更和额外文件；不打包模型及本地环境。

## 未完成的公开版门槛

1. **真实 VLA 验收**：本地无可用真实 checkpoint、LIBERO 和已确认服务器资源；需要实际模型目录、权重路径、环境解释器和一份合法输入。先验收一条路线，再扩大支持范围。
2. **LightVLA 原始证据**：历史实验结论仍缺随包可追溯记录，需队友回传原 JSON/日志或在固定条件下重测。
3. **SpecPrune**：统一 attach/资源传入/卸载恢复及原生前向尚不完整，不列为正式支持。
4. **来源和许可证**：LightVLA 继承实现未核实为官方逐字快照；SpecPrune 来源/许可记录不完整，公开再分发前需核对。根 LICENSE 不自动覆盖第三方代码和权重。
5. **独立用户验收与展示材料**：需队友从发布包完整试用；真实模型效果图和演示视频不能由合成输出冒充。

候选包可用于内部验收与中期演示准备。公开仓库可诚实展示已完成源码与限制，但“完整可用的多方法加速工具箱”结论要等以上相应门槛完成。

## 本次环境及边界

Windows，Python 3.12.14、torch 2.3.0+cpu、transformers 4.40.1 的现有本地虚拟环境用于测试。不启动 GPU 实验、不连接未知服务器、不下载模型、不更改原始交接快照；生成的发布包不包含虚拟环境。

中期后计划真机实验和自研方法。当前不需要为了封装重新跑训练集；真实模型效果的验收仍需要实际推理输入与评估记录。
