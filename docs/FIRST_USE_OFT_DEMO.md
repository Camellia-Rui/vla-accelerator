# 只有工具箱时的 OpenVLA-OFT 展示

目标是让 Codex 在 `wxy@172.23.148.117` 上为一个初次使用工具箱的用户准备独立工作目录，完成一次新的真实闭环，再用仓库已有的大样本证据解释选择。历史记录不能冒充这次运行。

## 现场输入给 Codex 的话

> 我只有这个 VLA 加速工具箱，想在服务器 `wxy@172.23.148.117` 上试 OpenVLA-OFT 的 LIBERO-Object 模型。请读 `START_HERE.md`，先检查服务器网络、磁盘、GPU、CUDA 和已有软件。请在 `/home/wxy/Rui_work/midterm-oft-first-use-新的日期时间` 下建立独立的源码、模型权重、Python 环境、LIBERO 资源和实验结果目录。源码须选工具箱兼容的锁定后端；从官方来源获取匹配的 Object 检查点。环境必须新建，不复用其他成员的环境或修改他们的文件。记录来源、版本、安装命令和校验值。资源完整后，先跑原生模型，再在同一权重、任务和初始状态下运行加速闭环，保存新产生的逐回合记录和耗时。请说明兼容方法、成功率和速度；如果任何前提不满足，明确指出具体阻塞，不把工具箱自带的历史结果说成本次实测。

## Codex 应执行的顺序

1. 连接服务器并检查磁盘剩余空间、可写目录、CUDA GPU 和外网/模型源可达性。**空间不足时不启动大文件下载**；记录需要增加的容量。7B BF16 主参数本身约 14 GB，还需要视觉模块、动作头、环境及缓存。不要在磁盘不足时把权重偷偷写入共享目录。
2. 在 `/home/wxy/Rui_work/midterm-oft-first-use-新的日期时间` 内建立 `backend/`、`openvla-oft`（指向锁定后端 `backend/src/openvla-oft`）、`checkpoint/`、`env/`、`libero/`、`captures/` 和 `results/`。新环境和缓存都落在本目录。原始源码、模型和共享服务器其他目录只读。
3. 根据 `methods/vla_pruner/backend.lock.json` 克隆 `MINT-SJTU/VLA-Pruner` 并检出固定提交；其 `src/openvla-oft` 才是这一方法匹配的模型工程。单独克隆 `moojink/openvla-oft` 不能当成已经适配 VLA-Pruner。检查固定提交存在，记录实际 HEAD 和修改状态。
4. 用服务器已有的 conda 安装器创建**新的** Python 3.10 环境，按该提交的上游安装说明安装其定制 Transformers、OpenVLA-OFT 与 LIBERO 依赖，再安装本工具箱。记录 `python`、PyTorch、CUDA、Transformers 的实际导入路径和版本；不要用普通 PyPI Transformers 替代定制副本。
5. 从上游 OpenVLA-OFT 的 Object 权重发行页下载完整检查点到 `checkpoint/`，核验分片索引、processor、动作头、本体投影器和归一化统计。准备 LIBERO Object 的任务文件、资产、初始状态，以及工具箱要求的真实 observation 捕获。所有下载位置须明确且可复查。
6. 用 `core doctor` 和 `core project check --probe-env` 做静态与环境检查，再运行原生动作、保留全部 token 对照、实际剪枝和卸载恢复。资源就绪后建立 project.json，使用 `python -m core select --project project.json --tasks 0 --trials-per-task 1 --output results/新的目录` 自动运行与评估， 在相同检查点、任务、初始状态上完成新配对，保存命令、日志、动作和报告。先跑一对烟雾测试，再决定是否扩大。未完成完整样本量时只报告烟雾测试结果。
7. 展示已归档的 50 对 Object 留出实验时，明确标注“以前完成的实验”。按预先给定的成功率门槛运行 `core select`；不把这批结果当作新环境、新检查点的验收。

## 录制顺序

先录 Codex 收到上面的用户请求，然后录它检查服务器并创建独立目录、下载与安装的关键步骤。安装权重和依赖可能需要较长时间，允许剪掉等待画面，但保留开始命令、结束状态和版本记录。接着录一次**新输出目录**中的原生与加速闭环，打开报告查看同一初始状态、成功与否、查询耗时和每回合策略耗时。最后录 50 对历史报告的选择器演示并解释证据边界。若首次使用安装无法在展示时限内完成，可把安装过程提前单独录制；现场必须说明环境已在演示前建立，不能称为现场从零安装。

此流程需要服务器可连接、足够存储和模型下载权限。路径中的“新的日期时间”须替换成实际唯一目录名；不要覆盖已完成实验。每次重新核实容量和 GPU 占用。2026-11-13 的代码回归使用了已存在环境和只读权重，不属于从零安装演示。
