## 现场五分钟演示

1. 展示根 README 方法表，说明面向已有 VLA 项目的研究者，方法支持有边界。
2. 将真实用户源码目录传给 `python -m core doctor --workspace "实际模型目录" --output "runs/现场新目录"`。打开 `report.html`，展示解释器、源码线索、checkpoint 缺口和四方法状态。没有真实目录时可检查本工具箱，但须说明是自检，不是假装用户模型。
3. 按 `UNIFIED_RUNTIME.md` 使用已核验路径执行 `core run --method vla_pruner`，展示完整动作块；再执行 `core evaluate` 或查看已归档结果，展示原生对照、实际裁剪与卸载恢复。说明每个任务只有一个初始输入，延迟比是描述性结果，不是任务成功率。服务器不可用时直接说明正在查看历史记录，不假装现场推理。
4. 展示 `methods/lightvla/cli.py` 的真实用户工厂入口和 `methods/vla_pruner/INTEGRATION.md` 的固定后端接口。说明模型预处理、权重与动作 API 来自用户项目。
5. 展示 `docs/EVIDENCE.md` 和历史证据索引，说明如何避免只凭 token 数宣传效果。结束时展示待补的真实模型验收项。

本地已验证解释器可用 `.venv/Scripts/python.exe` 替换命令中的 `python`；该环境不随发布包分发。每次输出目录用新名字，避免覆盖旧记录。现场前准备环境并预跑，不依赖现场下载。建议录屏备份，但本包不冒充已经录制视频。
